# Project Master

## Project Vision

Build a simple restaurant intelligence app that helps a small restaurant owner understand sales, expenses, and profit without needing a complex enterprise system.

## Why This App Is Being Built

Many small restaurants have business data, but it is often scattered across files and hard to review quickly.

This project is being built to make that easier by:
- accepting uploaded files
- storing them safely
- converting them into structured imported rows
- showing simple business summaries on easy-to-read pages

## MVP Goal

The MVP goal is to create a working restaurant operations dashboard that can:
- upload sales and expense files
- store upload records
- generate imported data rows
- show dashboard metrics
- show sales and expense analytics
- show a simple profit overview
- provide beginner-friendly insight without advanced AI costs

## Current Strategy

Current strategy:
- use Supabase as the backend
- use SQL-backed tables for stored business data
- use Supabase Storage for uploaded files
- use rule-based insight logic first
- keep the product low-cost, simple, and reliable

This means the app focuses on:
- practical summaries
- clear pages
- simple calculations
- easy recovery and continuation later

## Future Roadmap Direction

Later, this project can grow into smarter restaurant intelligence, for example:
- stronger file parsing from real uploaded spreadsheets
- better daily, weekly, and monthly trend reporting
- smarter category analysis
- alerts for unusual costs or weak sales days
- assistant-style recommendations for pricing, stock, and menu planning
- more advanced AI-based insight after the low-cost foundation is stable
