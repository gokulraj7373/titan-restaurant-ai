# Titan Restaurant AI

Titan Restaurant AI is a simple restaurant business dashboard built with Next.js and Supabase.

The app helps a restaurant owner:
- upload sales and expense files
- store uploaded files in Supabase Storage
- track upload history
- generate demo imported sales and expense rows
- review sales, expenses, and profit summaries
- view simple rule-based business insights on the dashboard

## Main Pages

- `/dashboard` - main business dashboard
- `/upload/sales` - upload a sales file
- `/upload/expenses` - upload an expense file
- `/uploads` - upload history
- `/sales-imports` - imported sales rows
- `/expense-imports` - imported expense rows
- `/sales-analytics` - sales summaries and top selling items
- `/expense-analytics` - expense summaries and top expense categories
- `/profit-overview` - combined sales and expense summary

## How To Run Locally

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```

3. Open the app in your browser:

```text
http://localhost:3000
```
